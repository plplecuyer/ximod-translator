# Bases de traduction de mods

Déposez ici vos **traductions de mods** déjà réalisées (fichiers .eet, .sst,
.dsd, .json ou .xml). Elles servent de mémoire de traduction : au chargement
d'un mod, les lignes ayant les mêmes indicateurs (GRUP, Champ, ID, EDID) et la
même source sont traduites automatiquement et validées.

Les traductions de ce dossier **priment** sur celles des bases de jeux en cas de
clé identique (vos corrections l'emportent sur la version vanilla).

L'emplacement de ce dossier est configurable dans `Config.ini`
(section `[Bases]`, clé `ModBasesDir`).
